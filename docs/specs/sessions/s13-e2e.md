# s13 — E2E y presupuesto de peso

Estado: BLOQUEADA (D-19). Depende de: s9 (y s10-s12 para cubrirlos).

## Objetivo

Probar el bundle construido tal como lo verá una landing, sin red real.

## Archivos

- `playwright.config.ts`
- `e2e/host.html` (imita Elementor: CSS agresivo global sobre `input`, `select`, `button`, `label`,
  `*{box-sizing:content-box}`, dos contenedores, uno insertado tarde dentro de un "popup")
- `e2e/leadkit.spec.ts`
- `scripts/size.mjs` (lee `dist/manifest.json`, mide brotli de JS + CSS por formulario, falla
  sobre el presupuesto de D-19)
- `package.json` (scripts `e2e` y `size`)

## Reglas

- `page.route("**/wp-admin/admin-ajax.php", ...)` responde los casos: éxito, rechazo, HTML 502,
  sin respuesta (timeout). Cualquier otra petición de red fuera de `localhost` hace fallar el test
  (CA-18).
- Proyectos: Chromium y WebKit.
- Accesibilidad: completar el formulario solo con teclado; axe sin violaciones serias o críticas
  (agregar `@axe-core/playwright` requiere aprobación: pedirla en el handoff, no instalar).
